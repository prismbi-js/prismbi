PrismBI: Power BI-style reports from a few lines of TypeScript

You load data, describe a model with DAX-like measures, and declare pages of visuals as JSON. PrismBI handles querying, cross-filtering, slicers, formatting and theming. It runs in any framework, with first-class React bindings.

1 · What you write → what renders

Four short files produce the report on the right

import { DataModel } from 'prismbi';

export const model = new DataModel()
  .addTable('Sales', salesRows)      // any JSON array / CSV
  .addTable('Products', productRows)
  .addTable('Region', regionRows)
  .addDateTable('Date', '2024-01-01', '2025-12-31')

  // star schema: filters flow from dimensions to facts
  .addRelationship({ from: 'Sales[ProductId]', to: 'Products[Id]' })
  .addRelationship({ from: 'Sales[RegionId]',  to: 'Region[Id]' })
  .addRelationship({ from: 'Sales[OrderDate]', to: 'Date[Date]' })

  // calculated column (row context)
  .addCalculatedColumn('Sales', 'Profit', 'Sales[Amount] - Sales[Cost]')

  // measures – real DAX semantics (filter context, CALCULATE, time intelligence)
  .addMeasure('Total Sales', 'SUM(Sales[Amount])', { format: '$#,0' })
  .addMeasure('Margin %',    'DIVIDE(SUM(Sales[Profit]), [Total Sales])', { format: '0.0%' })
  .addMeasure('Sales LY',    'CALCULATE([Total Sales], SAMEPERIODLASTYEAR(Date[Date]))')
  .addMeasure('YoY %',       'DIVIDE([Total Sales] - [Sales LY], [Sales LY])', { format: '0.0%' })
  .addMeasure('Share of All', 'DIVIDE([Total Sales], CALCULATE([Total Sales], ALLSELECTED(Products)))');

// ad-hoc evaluation, handy in tests and APIs
model.evaluate('[Total Sales]', [{ target: 'Region[Name]', op: 'eq', value: 'West' }]);

2 · How it fits together

Five layers, each usable on its own

DataTable

Data

Columnar tables from JSON, CSV or column arrays. Types are inferred and hash indexes are built lazily.

DataModel

Semantic model

Relationships, measures, calculated columns, date tables, formats and a field list for building UIs.

Evaluator

DAX-like engine

Filter and row context, context transition, CALCULATE, iterators, ALLSELECTED, YTD and same period last year.

defineVisual

Visuals

SVG charts, cards, table, matrix and slicers, with data roles, format panes, tooltips and highlighting.

Report

Report runtime

Pages, grid layout, cross-filtering, bookmarks, themes, JSON save and load, events, plus React wrappers.
